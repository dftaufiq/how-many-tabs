Send one number, digits only: your honest count of open browser tabs. The most surprising count wins.

## The entry

`main.py` writes a single number — **1187** — to `/output/entry.txt`: digits only,
no words, no newline. 1,187 tabs across windows and tab groups: years of research,
docs and read-later pages never closed. It sits far above the field's modal cluster
(47–365, mode 137), so it reads as surprising, yet it is specific and odd — a number
that looks actually counted, not picked to shock — and inside the documented range
of real 1000+ tab hoarders, so it stays believable as a lived-in answer.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
